# Agent Note: 开机统计与统计页重构；文件+定时合一；应用图标；本机页对齐详情页

Status: implemented

## Problem

用户对「信息层级」连续提了四条不满，共同点是**每块卡片都在平均用力**：

- 「开机统计设计的不好，借鉴实时状态」——实时状态页（LiveStats）有主次：大数字 + 环形 + 迷你趋势 +
  小指标网格；而开机统计只有一张柱图 + 一列长列表。
- 「统计页面设计的也很奇怪」——六块卡片平铺，「总览」里 6 个等宽 Stat 挤一排，数字不分主次。
- 「文件管理和定时任务不要设置成两个按钮」——两个并列小按钮孤零零挂在横幅下面，既占位又割裂。
- 「本机和设备控制详情页要保持一致」——本机页自己一套版面（系统卡/实时卡/磁盘卡/硬件/配对），
  与详情页的区块顺序完全不同，两页之间切换要重建空间记忆。

另外两条功能性需求：应用与进程要显示真实图标；APK 每次签名不同导致必须卸载才能装。

## Decision

1. **开机统计**（`UptimePanel` + `UptimeStat` + `UptimeBarChart`）：4 个大数字块（本月开机/启动次数/
   平均单次/最长单次，环比徽章）+ 趋势面板（与 LiveStats 的迷你趋势同款容器，本月柱高亮）+
   紧凑两列启停明细。环比做除零保护：上月为 0 时不显示百分比，改给「上月无记录」等具体原因。
2. **统计页**（`StatsPanel` + `StatsHero`）三层：主视觉大卡（唯一 ≥24px 的主数字 + 迷你趋势 + CPU/内存双环）
   → 规模指标网格（4 块小砖，不再用等宽 Stat）→ 明细两列（`items-start`，不强拉等高）。
3. **文件+定时合一**（`DeviceToolsDrawer`）：一个抽屉内部 tab 切换，两面板同时挂载用 `hidden` 切，
   切回来保留目录与列表状态；详情页只留一个整宽入口卡。返回按钮移到横幅标题行首位、36px 热区。
4. **本机页对齐详情页**：改成同一顺序与栅格（身份卡 → 管理工具 → 电源/音量/媒体 →
   实时状态+硬件 → 开机统计 → 应用与进程），只多一块本机独有的「配对与管理」。
   顺带把本机也接上了电源/音量/媒体/文件/定时能力（Agent 对 loopback 免令牌，本来就能用，
   只是之前没暴露）。
5. **应用图标**：Go 侧解析 PE `.rsrc` 取 `RT_GROUP_ICON` 最大项拼成单条目 `.ico`（纯标准库，
   支持**命名资源**——`cmd.exe` 的图标挂在名字上而不是数字 ID），256 条 LRU 缓存；
   新端点 `GET /apps/icon?exe=`；前端 `<img>` + `onError` 回退字母占位，用 IntersectionObserver
   只让接近视口的行发请求。
6. **APK 固定签名**：CI 从 Secrets 取 keystore（base64），拿不到就**直接失败**而不是现生成一个。

## Alternatives considered

- **统计页保留 6 块平铺只调间距**：层级问题不是间距问题，主数字不突出就还是「都差不多重要」。放弃。
- **开机统计只留柱图 + 把明细折叠**：用户要的是「像实时状态那样有层次」，折叠不算层次。放弃。
- **文件与定时保持两个按钮但换个位置**：两个入口并列本身就让用户在选择「用哪个」上多花一步，
  合成一个抽屉 + 内部 tab 才是真的少一次决策。放弃。
- **本机页另做一套「专属」组件**：会与详情页持续分叉，正是这次不一致的成因。改为复用同一批组件。放弃。
- **图标用 `ExtractIconExW`（shell32）**：能覆盖 Store 应用（notepad/taskmgr），但要先取 HICON
  再转图像，还得处理 Alpha 通道与尺寸，属另一条路；本任务范围内先做 PE 资源解析，
  覆盖不到的（exe 里根本没有图标资源）回退字母占位。列为后续可选项。
- **CI 里把 keystore 提交进仓库**：等于把签名私钥公开。放弃，走 Secrets。

## Consequences

收益：三个页面有明确的视觉主次；详情页只有一个管理入口；本机页与详情页一致且能力补齐；
应用列表有真实图标；APK 可覆盖安装。

代价与边界：
- 开机统计卡比改动前高约 60px（多了大数字区），仍低于同一行的 LiveStats。
- 统计页主数字做了 truncate 兜底，运行时长到 3 位数天数时极窄屏会省略号（不溢出）。
- 应用图标覆盖不到 Win11 的 store 存根应用（`notepad.exe`/`taskmgr.exe`/`mstsc.exe` 的 exe 里
  没有 `RT_ICON`）；iOS/Safari 的 WKWebView 不支持 `<img>` 渲染 ICO，会回退占位。
- 图标端点的令牌放在 query（`<img>` 发不出 Authorization 头），跨机看图时令牌可能进访问日志；
  本机请求免令牌。若在意，后续可改成一次性图标票据。
- 固定签名的 keystore 已存入仓库 Secrets（`ANDROID_KEYSTORE_BASE64` 等三项），
  keystore 文件本身在 `.gitignore` 里，未入库；实测从 base64 还原后签名指纹与原 APK 一致。
