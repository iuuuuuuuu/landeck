# Agent Note: 客户端自带被控端 + 托盘保活 + 本机页面向"自己这台电脑"

Status: implemented

## Problem

用户在一台**新电脑**上装了 v1.0.5 的客户端，得到三个现象：

1. 「本机」页一片"连接失败，请确认设备在线且在同一局域网"；
2. 没有托盘图标；
3. 硬件、实时状态全空。

逐个查下来是三个独立缺陷：

- **没有被控端**：安装包只含客户端，那台机器上根本没有 `landeck-agent`。
  「本机」页读的是 `127.0.0.1:8420`，没有进程监听，自然全空。
- **托盘被自己销毁**：`TrayIconBuilder::build(app)` 的返回值被直接丢弃。
  Tauri 的 `TrayIcon` 在 drop 时会把图标从通知区移除 —— 于是"建好即消失"。
  另外 v1.0.5 发布时托盘代码还没写，用户装的包里确实没有。
- **全新配置被 401**：`allowLocalNoAuth` 只写在 `repair()`（迁移老配置）里，
  没写进 `Default()`。新机器第一次生成配置走 `Default()`，这个开关是 `false`，
  于是本机免令牌不生效，本机页所有请求 401。

## Decision

1. **把被控端打进客户端安装包**（`bundle.resources`），并在客户端启动时**自动拉起**，
   失败不阻断客户端。用户装一个包就能在本机页看到数据，不用再下载第二个安装包。
   数据目录放客户端自己的 `agent-data`，不与被控端独立安装抢配置。
   找不到资源目录时，本机页给出「启动本机被控端」按钮兜底。
2. **托盘句柄交给 `app.manage(tray)` 保活**，菜单：打开 LanDeck / 本机状态 / 退出；
   左键单击直接显示窗口（比"先弹菜单再点"少一步）。
3. **`Default()` 里显式 `AllowLocalNoAuth: true`**，新配置文件同样走一遍 `repair()`。
4. 本机页顺带补齐：配对码 + 已授权客户端管理（拿码、撤销）、硬件全量罗列（去掉页签）、
   时长改中文（不再出现 `2d` / `3h`）、统计页把「本机」纳入设备选择、扫描按 IP 排除自己。

## Alternatives considered

- **本机页只提示"请先安装被控端"、不带二进制**：省 11 MB，但用户必须再下一个包，
  而他装客户端的目的本来就是"控制 PC"，多一个安装环节就是把问题推回给他。放弃。
- **让客户端通过 HTTP 远程启动对端 Agent**：需要目标机已有 Agent，解决不了"新机器什么都没有"。放弃。
- **托盘图标用 `std::mem::forget` 保活**：能保住，但泄漏且不可控；`app.manage` 是官方推荐做法。放弃。
- **扫描结果靠 `node.self` 字段排除本机**：原生 UDP 帧里没有这个字段，实测仍会扫到自己。
  改成按本机 IP 比对（`local_ip` + `location.hostname` + loopback 字面量）。放弃 `self` 单一路径。
- **统计页只统计已配对设备**：本机没配对就看不到自己的数据，与"本机页能看到"自相矛盾。放弃。

## 追加：移动端与 CI 的两个坑（第一次打 tag 时暴露）

1. **Android 编译失败**：`tauri::menu` / `tauri::tray` 在移动端不存在，`WebviewWindow::unminimize`
   也没有。托盘与"拉起被控端"都是桌面端语义，必须用 `#[cfg(desktop)]` 圈起来，
   移动端给同名的桩实现（`agent_status` 恒 false、`agent_start` 直接返回"手机上不能启动"）。
2. **macOS 打包失败**：`go: command not found` —— desktop job 里没有 Go，
   而"准备被控端"这步要现编二进制。加 `actions/setup-go`，版本对齐 `go.mod` 的 1.26。

教训：**把"临时编出来的二进制"引入打包流程后，每个需要它的 job 都要补对应工具链**，
否则只有在那个平台的 job 才会红，本地永远看不到。

## Consequences

收益：新电脑上装客户端即可用（被控端随之启动）；托盘稳定存在；本机页自助发现"没 Agent"并一键修复。

代价：
- 客户端安装包从 1.6 MB 涨到约 12 MB（内含被控端二进制）。
- 自动拉起被控端意味着**客户端一启动，这台机器就对外提供被控服务**（默认端口 8420）。
  这是产品形态的默认值，但需要在文档里写清楚；权限仍由配对码约束。
- 托盘图标是否"看得见"无法用程序验证（Win11 的 UIA 取不到通知区按钮，消息窗口不可枚举），
  只能靠人工确认；本次交付按"代码路径正确 + 进程存活"申报，不宣称视觉已验收。
